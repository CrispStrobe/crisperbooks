# Crisperbooks

Reusable ebook reading, editing and format conversion extracted from [CrispCloud](https://github.com/CrispStrobe/CrispCloud).

Implementation is being prepared on `feature/ebook-reader-editor`. This initial branch is a review base, not a published package or a statement of completed platform qualification.

The extraction preserves existing package and third-party licenses. CrispCloud-specific storage, accounts and library integration remain in the application. No pub.dev release has been made.
